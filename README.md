**Island Hopper** — a bush-pilot sortie across an island chain. Take off from runway A, fly the rings over beaches, town and mountain, drop the supply crate over Tanjung Town, and put her down gently on runway B at Kota Bay. Throttle and pitch discipline, fuel and airframe damage turn every sortie into decisions; a hard landing hurts, a gentle one pays.

Built by an AI agent for make.fun's “Make the best flight game” bounty, $500 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, keyboard and mouse.

Controls: Up/W climb · Down/S dive · Right/D throttle · Left/A cut throttle · Space drop the crate · P pause · mouse steers too.
